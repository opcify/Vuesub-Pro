Voice Clone, in three steps.

CosyVoice 3 0.5B does zero-shot voice cloning from a short reference clip. Vuesub handles the runtime install, the audio normalisation, and the Whisper-based reference transcription — you just upload, type, and generate.

01 — UPLOAD

Drop in a clean clip

5–30 seconds, single speaker, WAV or MP3. Vuesub normalises it to 16 kHz mono PCM and stores it under ~/.vuesub/speakers/. Whisper auto-transcribes — no need to type out what was said.

02 — VERIFY

Edit the transcript if needed

The auto-transcript is shown inline. CosyVoice's output quality depends on alignment between transcript and audio — if Whisper got it wrong (especially on accented or musical clips), one click fixes it.

03 — GENERATE

Type and hit Generate

Cold start ~60 s on Mac CPU; subsequent generates with the same speaker are warm at ~3.5× realtime. The "Just generated" card auto-plays the result, with one-click Save As.

One-time setup. The CosyVoice runtime is too heavy to bundle (~6.5 GB), so it installs on demand the first time you download a model. You'll need three tools on your PATH first — Vuesub detects what's missing and shows install snippets inline.

python

3.10–3.12 · CosyVoice's torch pin

brew install python@3.12

uv

venv + dep installer · 10× faster than pip

curl -LsSf https://astral.sh/uv/install.sh | sh

git

shallow-clones the CosyVoice repo

xcode-select --install
Heads up — Voice Clone is fully tested only on Apple Silicon Mac. Windows and Linux binaries are produced from CI but the runtime path hasn't been live-tested on those platforms. Please open an issue if anything breaks.

Caption that doesn't waste your time.

Caption mode is a Final-Cut-style editor on top of Whisper. The waveform timeline pans and zooms, every caption clip is draggable, and transcript edits round-trip back to the timeline.

Editor

  • Waveform timeline with per-pixel detail at any zoom (⌘+ / ⌘− / ⌘0)
  • Draggable caption clips — body to move, edges to resize
  • Inline text edits with auto-grow textareas, ⌘Z undo
  • Insert / split / merge / delete — per-row + button (auto-fills the gap), in-row ✂ to split at the caret, ↑ to merge with the row above, ⌘J to join a multi-row range
  • Variable playback (1× / 1.25× / 1.5× / 2×) without changing pitch

Languages & encodings

  • Auto-detect, or pin one of 16 languages
  • Near-instant 简/繁 conversion for Chinese transcripts (OpenCC)
  • Plays anything: WebM with Opus + AV1, MKV, FLAC, .ogg via Web Audio fallback
  • Local mode never leaves your machine — useful for NDA'd content

Export anywhere.

Vuesub writes four formats. Two of them — SRT and FCPXML — cover almost every workflow.

.srt

SRTPick this if unsure

SubRip — the universal timed-subtitle format. Plain text, numbered cues, HH:MM:SS,mmm ranges. Practically every player and editor accepts it.

  • Players: VLC, IINA, mpv, QuickTime, smart TVs.
  • Upload: YouTube, Vimeo accept SRT directly.
  • Editors: Premiere Pro, DaVinci Resolve, Final Cut Pro, CapCut, Camtasia.
  • Burn-in: ffmpeg -vf subtitles=in.srt.
.fcpxml

FCPXMLFor Final Cut Pro

A real Final Cut Pro project (FCPXML 1.11) where every segment is a native, restyleable <caption> on lane 1 — not burnt-in titles.

  • Frame-aligned to your chosen rate — no "not on edit frame boundary" warnings.
  • Match your project: 1080p · 30 / 24 / 25 / 29.97 / 60.
  • Import: File → Import → XML… → pick the .fcpxml.
  • Drop-frame timecode for 29.97 and 59.94, NDF for everything else.
.vtt

VTT

WebVTT for HTML5 <video> with a <track> element. Same shape as SRT, with . instead of , and a WEBVTT header.

Pick this for self-hosted video on a website you control.

.txt

Plain text

Just the lines, one per segment. No timing.

Use it for the content, not the timing — turning a podcast into a blog post, dropping a transcript into Notion, feeding text to an LLM, sharing notes.

First launch & system requirements.

One-time steps for each platform, plus what your hardware needs to handle.

First launch on macOS

The app isn't yet signed with an Apple Developer ID, so macOS will refuse to open it with "Vuesub is damaged and can't be opened". Drag Vuesub.app from the DMG into /Applications, then strip the quarantine attribute:

sudo xattr -rd com.apple.quarantine /Applications/Vuesub.app

Same effect a Developer-ID signature would have, just done by hand.

System requirements

  • macOS 11 Big Sur or later · Apple Silicon (Intel via Rosetta supported but slower)
  • Windows 10 / 11 · x64 · WebView2 (preinstalled on Win 11)
  • Linux · x64 · Debian / Ubuntu · needs libwebkit2gtk-4.1-0
  • Disk · ~1 GB for the app + Whisper models you download (~75 MB → 3 GB)
  • Voice Clone · adds ~6.5 GB on first model download
  • RAM · 8 GB OK for Caption · 16 GB+ recommended for Voice Clone
