Why Vuesub

Whisper accuracy, locally

Runs OpenAI's Whisper models on your machine via faster-whisper. tiny → large-v3, multilingual, punctuation-aware. No upload required.

Cloud optionnew

Drop in your OpenAI API key in Settings to optionally route through whisper-1. Audio is auto-transcoded to 16 kbps Opus before upload to keep it tiny.

FCP-style editor

Waveform timeline with per-pixel detail at any zoom, draggable caption clips, inline text edits, multi-select merge, ⌘Z undo. Switching back to a previously-loaded file is instant — the decoded waveform is cached.

Variable playback speednew

1× / 1.25× / 1.5× / 2× — review long recordings faster without changing pitch. Persists across sessions.

Plays anythingnew

WebM with Opus and AV1, MKV, FLAC, .ogg — Vuesub falls back to a Web Audio path when your system can't play a container natively.

Model managernew

Download, delete, or import Whisper models from the Settings panel. Watch byte-level progress + ETA. Drop in a custom CT2 model as a .zip.

16 languages, persistednew

Auto-detect by default, or pin English, 中文 (Mandarin / Cantonese), 日本語, Español, Italiano, Deutsch, ไทย, Русский, 한국어, Nederlands, Français, हिन्दी, العربية, עברית. Near-instant 简/繁 switch for Chinese transcripts (OpenCC dictionary preloads in the background).

Export anywhere

SRT, VTT, plain text, or FCPXML for Final Cut Pro at any frame rate / resolution. Captions land on the right edit-frame boundary.

Offline & private

Local mode never leaves your machine. No account, no telemetry. Cloud mode only sends what you explicitly choose to send.

Export formats

Vuesub writes four formats. Two of them — SRT and FCPXML — cover almost every workflow. Pick the one that matches what you'll do next.

.srt

SRTPick this if unsure

SubRip — the universal timed-subtitle format. Plain text, numbered cues, HH:MM:SS,mmm ranges. Practically every player and editor accepts it.

  • Players: VLC, IINA, mpv, QuickTime, smart TVs. Drop MyVideo.srt next to MyVideo.mp4 and most players load it automatically.
  • Upload: YouTube, Vimeo accept SRT directly as a caption track and run auto-translation on top.
  • Editors: Premiere Pro, DaVinci Resolve, Final Cut Pro, CapCut, Camtasia — import as a subtitle track with timing intact.
  • Burn-in: ffmpeg -vf subtitles=in.srt to bake captions into the video.
.fcpxml

FCPXMLFor Final Cut Pro

A real Final Cut Pro project (FCPXML 1.11) where every segment is a native, restyleable <caption> on lane 1 — not burnt-in titles.

  • Frame-aligned: offsets and durations snap to the rate you choose, so FCP doesn't show "not on an edit frame boundary" warnings.
  • Match your project: pick the same resolution & FPS as your edit. Common picks: iPhone / cameras → 1080p · 30, cinema (24p) → 1080p · 23.976, NTSC broadcast → 1080p · 29.97, PAL → 1080p · 25, 4K → 2160p · 30 or 24.
  • Import: in FCP, File → Import → XML… — pick the .fcpxml. Captions appear on the timeline; copy them onto your edit.
  • Drop-frame timecode (DF) is used for 29.97 and 59.94, NDF for everything else.
.vtt

VTT

WebVTT — the format browsers expect when you attach captions to an HTML5 <video> with a <track> element. Same shape as SRT, with . instead of , in timestamps and a WEBVTT header.

Pick this if you're publishing the video on a website you control and want captions to show without a third-party player.

.txt

Plain text

Just the lines, one per segment. No timing.

Use it for the content, not the timing — turning a podcast into a blog post, dropping a transcript into Notion or Google Docs, feeding text to search or an LLM, sharing notes with someone who doesn't need the video.

First launch on macOS

The app isn't yet signed with an Apple Developer ID, so macOS will refuse to open it with "Vuesub is damaged and can't be opened" the first time. Drag Vuesub.app from the DMG into /Applications, then strip the quarantine attribute: 

sudo xattr -rd com.apple.quarantine /Applications/Vuesub.app

After that, double-click to launch normally. Same effect a Developer-ID signature would have, just done by hand.

System requirements

  • macOS 11 Big Sur or later · Apple Silicon (Intel via Rosetta supported but slower).
  • Windows 10/11 · x64. Includes WebView2 (preinstalled on Windows 11).
  • Linux · x64. Debian/Ubuntu via the .deb. Needs webkit2gtk-4.1 at runtime (apt: libwebkit2gtk-4.1-0).
  • Roughly 1 GB free disk for the app, plus the size of whichever Whisper model you download (tiny → 3 GB).
Heads up — Windows & Linux builds are untested.

We've shipped Windows x64 and Linux x64 binaries, but they haven't been put through real-world testing yet. If you hit anything broken, please open an issue so we can fix it.
