Why Vuesub

Whisper accuracy, locally

Runs OpenAI's Whisper models on your machine via faster-whisper. tiny → large-v3, multilingual, punctuation-aware. No upload required.

Cloud optionnew

Drop in your OpenAI API key in Settings to optionally route through whisper-1. Audio is auto-transcoded to 16 kbps Opus before upload to keep it tiny.

FCP-style editor

Waveform timeline with per-pixel detail at any zoom, draggable caption clips, inline text edits, multi-select merge, ⌘Z undo.

Plays anythingnew

WebM with Opus and AV1, MKV, FLAC, .ogg — Vuesub falls back to a Web Audio path when your system can't play a container natively.

Model managernew

Download, delete, or import Whisper models from the Settings panel. Watch byte-level progress + ETA. Drop in a custom CT2 model as a .zip.

16 languages, persistednew

Auto-detect by default, or pin English, 中文 (Mandarin / Cantonese), 日本語, Español, Italiano, Deutsch, ไทย, Русский, 한국어, Nederlands, Français, हिन्दी, العربية, עברית. 简/繁 switch for Chinese transcripts.

Export anywhere

SRT, VTT, plain text, or FCPXML for Final Cut Pro at any frame rate / resolution. Captions land on the right edit-frame boundary.

Offline & private

Local mode never leaves your machine. No account, no telemetry. Cloud mode only sends what you explicitly choose to send.

Pick the right Whisper model

Models download lazily on first use and cache to your home directory. Pick the smallest that gives you the accuracy you need.

ModelDiskRAMNotes
tiny~75 MB~1 GBVery fast — quick drafts, low-power machines
base~145 MB~1 GBDefault. Reasonable accuracy on most laptops
small~485 MB~2 GBBetter accuracy, still CPU-friendly
medium~1.5 GB~5 GBStrong accuracy. CPU-only is sluggish
large-v3~3.1 GB~10 GBBest quality. GPU strongly recommended
openai/whisper-1——Cloud — uploads compressed audio to OpenAI

System requirements

  • macOS 11 Big Sur or later · Apple Silicon (Intel via Rosetta supported but slower).
  • Windows 10/11 · x64. Includes WebView2 (preinstalled on Windows 11).
  • Linux · x64. Debian/Ubuntu via the .deb. Needs webkit2gtk-4.1 at runtime (apt: libwebkit2gtk-4.1-0).
  • Roughly 1 GB free disk for the app, plus the size of whichever Whisper model you download (tiny → 3 GB).
