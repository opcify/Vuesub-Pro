一次性配置与前置要求 →

CosyVoice 运行时体积较大（约 6.5 GB），无法直接打包，会在你首次下载模型时按需安装。Vuesub 会自动检测缺少的依赖并在界面上给出安装命令。你需要先把以下三个工具加入 PATH：

  • python 3.10–3.12 — CosyVoice 的 torch 版本要求。 brew install python@3.12
  • uv — venv 与依赖管理器，比 pip 快 10 倍。 curl -LsSf https://astral.sh/uv/install.sh | sh
  • git — 浅克隆 CosyVoice 仓库。 xcode-select --install

注意。 声音克隆目前仅在 Apple Silicon Mac 上完整测试。Windows 与 Linux 版本由 CI 构建，但运行时路径尚未在这两个平台实测。如遇问题，欢迎 提交 issue 反馈。

导出

四种格式。覆盖所有工作流。

.srt

SRT 默认

通用格式。哪儿都能播。

.fcpxml

FCPXML

Final Cut Pro 原生字幕。逐帧对齐。

.vtt

VTT

HTML5 <track> 标签。适合自托管视频。

.txt

纯文本

只有文字内容。喂给 LLM，整理成博客文章。

格式细节与播放器支持 →

SRT。 SubRip — 通用的时间码字幕格式。纯文本、编号字幕段、HH:MM:SS,mmm 时间格式。播放器：VLC、IINA、mpv、QuickTime、智能电视。上传：YouTube、Vimeo 直接接受 SRT。剪辑软件：Premiere Pro、DaVinci Resolve、Final Cut Pro、剪映、Camtasia。硬字幕烧录：ffmpeg -vf subtitles=in.srt。

FCPXML。 一份真正的 Final Cut Pro 项目（FCPXML 1.11），每段字幕都是 lane 1 上可重新设计样式的原生 <caption> — 不是烧录的字幕。帧率精确对齐（1080p · 30 / 24 / 25 / 29.97 / 60）。29.97 与 59.94 使用 drop-frame 时间码，其他帧率使用 NDF。导入方式：File → Import → XML… → 选择 .fcpxml。

VTT。 配合 HTML5 <video> 与 <track> 标签的 WebVTT 格式。结构与 SRT 类似，时间分隔符是 . 而非 ,，文件以 WEBVTT 头部开始。适合你自己控制的站点托管视频。

纯文本。 只有文字，每段一行，没有时间码。适合需要 内容 而非时间的场景 — 把播客整理成博客、把转录稿丢进 Notion、把文本喂给 LLM、分享笔记。

配置

首次启动与系统要求。

在 macOS 上首次启动

去除 Gatekeeper 的隔离属性以打开应用：

sudo xattr -rd com.apple.quarantine /Applications/Vuesub.app

效果等同于 Developer-ID 签名，只是手动操作。

系统要求

  • macOS 11+ · Apple Silicon 原生
  • Windows 10 / 11 · x64 · WebView2
  • Linux · x64 Debian/Ubuntu · libwebkit2gtk-4.1
  • 字幕：8 GB 内存 · 声音克隆：16 GB+
  • 硬盘：应用约 1 GB + 模型 75 MB–3 GB · 声音克隆另需 +6.5 GB

下载一次即可。无需账户。无需上传。完全离线运行。
